Hesabe Payment Gateway

Complete setup guide for integrating Hesabe Payment Gateway into your system

⚠️ Important Notice

This plugin is not allowed for sale. We encourage our merchants to report any unauthorized sales. Hesabe will take serious actions against violations.

1

Configuration

After installing the Hesabe Payment plugin, click on the menu in the top right corner and select "Website". When the page loads, you'll see a menu at the top. Click on "Configuration" as shown in the image below.

2

Payment Acquirer

Once the dropdown appears, look for "Payment Acquirer" and click on it. Find the highlighted section in the image below. When you click it, a menu will appear that includes the HESABE payment gateway plugin.

3

Plugin Activation

After the page loads, refer to the image below to activate the plugin. Make sure to follow the highlighted areas for proper activation.

4

Test Mode Configuration

Please ensure that test credentials are properly configured before proceeding. This allows you to test transactions safely without processing real payments.

5

Live Mode Setup

Please ensure that production credentials are configured before enabling live mode. This step is crucial for processing real transactions.

Need help with live credentials? Contact us at support@hesabe.com

6

Disable Plugin

To disable the plugin, simply click on the disable radio button and save your changes. This will deactivate the payment gateway.
